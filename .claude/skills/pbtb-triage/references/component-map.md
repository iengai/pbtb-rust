## Tooling quirks (Windows host)

- Prefix AWS CLI calls that take `/aws/...` or `/scalable-cluster/...` paths with
  `MSYS_NO_PATHCONV=1` in Git Bash, or call from Python (`pbtb_ops.py` does).
- `set -e` does **not** stop a multi-step command in the Bash tool; guard each
  gate with `|| exit 1` and check `${PIPESTATUS[0]}` after pipes.
- Bash-tool heredocs collapse `\\` and choke on `\u{…}`; write edit scripts with
  the Write tool and run `python <file>`.
- Console is cp932: `sys.stdout.reconfigure(encoding="utf-8")` before printing
  logs with box-drawing or emoji characters. The AWS CLI is Python too: run it
  with `PYTHONUTF8=1` (pbtb_ops.py does) or it dies mid-output on such logs and
  what reaches you looks like corrupt JSON.
- Docker Desktop drops out intermittently; the dev container `app-node` (and
  `dynamodb-local`) come back with it. Host `cargo` works for check/clippy/test as
  an early signal; the container is the reference toolchain (clippy 1.88).
